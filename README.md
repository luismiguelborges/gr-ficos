
# Raio-X da Juventude

Painel de análise de dados sobre condições de vida, educação
e inclusão digital, com foco em políticas e iniciativas sociais.

## Tecnologias

- HTML5 e CSS3
- JavaScript
- Chart.js
- GitHub Pages

## Indicadores

- Acesso à internet nos domicílios brasileiros
- Frequência escolar bruta por faixa etária
- Comparação histórica dos indicadores disponíveis

## Fontes

- IBGE: https://www.ibge.gov.br/
- IBGE — Educação 2024:
  https://biblioteca.ibge.gov.br/visualizacao/livros/liv102180_informativo.pdf
- IBGE — Internet nos domicílios:
  https://agenciadenoticias.ibge.gov.br/agencia-noticias/2012-agencia-de-noticias/noticias/47410-internet-chega-a-95-domicilios-do-pais-em-2025
- INEP: https://www.gov.br/inep/pt-br

## Metodologia

Os gráficos apresentam indicadores de fontes oficiais.
Cada medida deve ser interpretada de acordo com sua definição,
população de referência e período.

Os indicadores domiciliares não representam exclusivamente
os jovens. Frequência escolar bruta não equivale a conclusão
escolar nem à frequência regular.

## Publicação

O site pode ser publicado gratuitamente com GitHub Pages,
utilizando os arquivos estáticos deste repositório.

## Privacidade

Não publique dados pessoais ou registros individuais identificáveis.
